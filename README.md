## Projetos

### ARCA: Comparador Inteligente de Preços

Plataforma mobile e web que compara preços entre supermercados e ajuda o usuário a economizar nas compras.

Projeto de TCC desenvolvido em equipe de quatro pessoas. Fui responsável pelo banco de dados e pela implementação completa do código; os colegas atuaram na documentação e na prototipação.

- Mais de 58 mil produtos monitorados
- Busca híbrida (ILIKE, trigram e embeddings), reduzindo as comparações de 40 segundos para menos de 1 segundo
- Sincronização reduzida de 27 minutos para cerca de 2 minutos
- Portal B2B para mercados gerenciarem produtos e importarem CSV

**Tecnologias:** Ionic • Angular • Next.js • PostgreSQL • Supabase • MongoDB • Python

🔗 [Repositório](https://github.com/rodrigopereiradevelopment/arca-ionic)

### EditeCC: Editor Acadêmico com IA Local

Editor open source para trabalhos acadêmicos em normas ABNT, com IA executando totalmente offline.

Projeto individual. O objetivo é que a comunidade ajude na manutenção: já recebi quatro sugestões de melhoria, uma delas enviada por outro desenvolvedor, que após análise foi integrada ao código.

- Desktop multiplataforma (Windows, Linux e macOS)
- Tradução offline com NLLB-200
- Sumarização automática de textos
- Geração automática de apresentações em PowerPoint
- Sem dependência de APIs externas

**Tecnologias:** Tauri • Next.js • Transformers.js

🔗 [Repositório](https://github.com/rodrigopereiradevelopment/editecc)

### Quero Café Bar: Sistema de Gestão para Estabelecimentos

Sistema completo de gestão, iniciado como exercício da disciplina de Programação para Dispositivos Móveis e expandido por iniciativa própria com autenticação, controle de acesso e testes automatizados.

- Autenticação JWT com controle de acesso por papéis (RBAC)
- 235 testes automatizados
- Aplicação Android com Capacitor
- Backend em NestJS e frontend em Ionic

**Tecnologias:** NestJS • Ionic • TypeScript

🔗 [Repositório](https://github.com/rodrigopereiradevelopment/quero-cafe-bar)
